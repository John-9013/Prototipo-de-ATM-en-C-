# Prototipo de ATM en C++

Prototipo de cajero automático desarrollado en **C++** aplicando Programación Orientada a Objetos (POO).

## Descripción del Proyecto
Este proyecto implementa una estructura modular orientada a objetos para simular operaciones y presentaciones
informativas con clases personalizadas.

## Archivos Principales
- `presentacion.cpp`: Código fuente principal que contiene la clase `PresentacionPersonal` y la lógica de
- ejecución en consola o interfaz.
- `presentacion.exe`: Archivo ejecutable compilado del proyecto.
